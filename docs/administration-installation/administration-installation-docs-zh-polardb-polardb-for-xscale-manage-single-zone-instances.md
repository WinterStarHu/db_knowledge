本文介绍单可用区实例的运维操作。

创建实例

在创建PolarDB-X实例时，部署拓扑可选择单可用区，详细步骤请参见创建实例。

查看实例

购买成功后，您可在实例列表页和实例详情页查看实例的可用区信息。

实例列表

在实例列表页，可以查看实例的可用区信息。实例可用区信息位于实例列表的可用区列中。

实例详情

在实例详情页，可以查看实例的可用区信息。

实例可用区信息位于基本信息区域的可用区字段中，各计算节点的可用区位于拓扑信息区域的计算节点列表的可用区列中。

常见问题

Q：前期实例创建时选择了单可用区，后期有跨机房容灾的诉求，能否不停机变更为三可用区？

A：单可用区可以在线变更可用区，一键升级为三可用区形态，详细可以参见单可用区变更为三可用区。

在实例列表的操作列单击迁移可用区，在弹窗中将部署方式选择为三可用区，分别设置主节点可用区、备节点可用区和日志节点可用区，选择对应的VPC和虚拟交换机，设置切换模式（立即切换或运维时间内切换）后单击确定。
