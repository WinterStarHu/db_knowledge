# 支持ograc标准开发接口

## 可获得性

本特性自ograc 1.0.0 版本开始引入。

## 特性简介

支持ODBC及JDBC标准接口。

## 客户价值

提供业界标准的ODBC及JDBC接口，保证用户应用程序能与ograc数据库进行交互，增强了应用程序的可移植性、扩展性和可维护性。

## 特性描述

目前支持标准的ODBC及JDBC接口，其中ODBC支持Win32、Win64平台，JDBC无平台差异。

## 特性增强

无。

## 特性约束

无。

## 依赖关系

ODBC依赖unixODBC，使用ODBC之前需先安装unixODBC。jdbc的使用依赖JDK环境，需先安装JDK。
