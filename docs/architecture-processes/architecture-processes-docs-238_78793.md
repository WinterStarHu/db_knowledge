Database Audit is a professional, efficient, comprehensive, and real-time database security monitoring product independently developed by Tencent Cloud. It enables real-time recording of TencentDB activities and provides fine-grained auditing compliance management for database operations.
TencentDB for SQL Server provides Database Audit capabilities, recording database access and SQL statement execution, helping enterprises implement risk control and improve data security levels. Simultaneously, it supports custom highand low-frequency storage, which can significantly reduce the usage cost of Database Audit.
Use Cases Address audit risk Incomplete audit logs result in difficulties in tracing and locating security incidents.
Fails to meet the explicit requirements of National Cybersecurity Classified Protection (Level 3).
Fails to meet the requirements specified in industry information security compliance documents.
Address management risk Misoperations, non-compliant operations, and overstepping of authority by technical personnel compromise the secure operation of business systems.
Misoperations, malicious operations, and tampering by third-party development and maintenance personnel.
Super administrators have excessive privileges that cannot be audited or monitored.
Address technical pain points SQL injection in database systems and malicious extraction of database and table information.
A sudden surge of database requests not caused by slow logs makes it impossible to quickly pinpoint the issue.
Billing Billing is based on the audit log storage size in pay-as-you-go mode. The billing cycle is one hour. Usage lasting less than one hour will be charged as one full hour.
For specific product pricing, see Database Audit Billing Overview.
Supported Versions and Architecture Database Audit currently supports the following database editions: 2012, 2014, 2016, 2017, 2019, 2022, and 2025 Enterprise.
Database Audit currently supports the following instance architectures: Dual-node (local disk), Read-Only instances (local disk), Single-node (cloud disk), Dual-node (cloud disk), Multi-node (cloud disk), and Read-Only instances (cloud disk).
Advantages Full Auditing Database Audit comprehensively records database access and SQL statement execution, meeting users' audit requirements to the greatest extent and ensuring database security.
Efficient Auditing TencentDB collects and records audit logs through Extended Events, enabling more comprehensive and accurate recording of database operations.
Long-term retention Supports long-term log storage based on business needs to meet compliance requirements.
Architecture Features Adopting a multi-node deployment architecture to ensure service availability. Streaming logging prevents tampering. Multi-replica storage guarantees data reliability.
