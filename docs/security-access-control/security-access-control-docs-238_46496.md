Major Version Lifecycle Note:
Microsoft has stopped extended support for several SQL Server versions. If you continue to use instances of the corresponding versions, your applications and business may face various risks, including but not limited to security vulnerabilities, application compatibility issues, compliance risks, and potential security risks caused by other non-functional issues. It is recommended that you select SQL Server 2016 Enterprise or later versions during instance purchase. You can also upgrade existing instances to SQL Server 2016 Enterprise or later versions to ensure business security and stability.
