创建并连接第一个集群

流程概述：

在控制台选择引擎并完成基础配置，以创建集群。

为集群创建用于登录的数据库账号和密码。

获取集群的连接地址和端口。

使用客户端工具或代码连接数据库，执行查询以验证连通性。

步骤一：创建集群

登录PolarDB 控制台，进入集群创建页面。

根据业务场景，从适用范围选择合适的引擎。

节点规格：首次测试建议选择最低配置，以控制成本。

网络配置：使用专有网络，并暂时关闭公网访问，以提升安全性。

步骤二：创建数据库账号

集群创建成功后，在集群管理页面的账号管理中，创建一个高权限账号或普通账号，并设置一个包含大小写字母、数字和特殊字符的强密码。

步骤三：获取连接地址

在集群管理页面的基本信息中，找到并复制集群的主地址和端口号，例如pc-xxxx.mysql.polardb.rds.aliyuncs.com:3306。

步骤四：连接并验证

可使用任何标准的数据库客户端工具进行连接。以 MySQL 命令行工具为例：

连接数据库 将上一步获取的地址、端口以及创建的账号密码替换到以下命令中。

mysql -h pc-xxxx.mysql.polardb.rds.aliyuncs.com -P 3306 -u <用户名> -p

验证连接 成功连接后，执行一条简单的SQL查询。如果返回数据库版本号，则代表第一个PolarDB集群已成功创建并连接。

SELECT VERSION();

计费说明

创建PolarDB集群会立即产生费用，主要包括计算节点、存储空间与备份存储等费用。为避免不必要的持续计费，用于测试或学习的集群，需在完成操作后及时释放资源，具体请参见计费概览 。
