本文汇总了在使用PolarDB集群过程中所有可能会收费的项目。

通常情况下，PolarDB集群中各计费项费用的大致占比如下图。

表 1. 计费项概览表

计费项 说明 支持的计费方式

计算节点

计算节点包括主节点和只读节点。

计算节点的费用与节点所在地域、节点规格以及使用时长有关。

按量付费+固定规格计算包

按量付费

包年包月

说明

关于计算节点的购买方式，请参见购买方式概览。

关于计算节点的规格类型和对应的定价细则，请参见计算节点规格和计算节点计费规则。

存储空间

存储空间是指数据文件、索引文件、日志文件（在线日志和归档日志）和临时文件等占用的空间。被占用的存储空间会产生费用。

存储空间的费用与数据量大小和存储时长有关。

按容量计费（按量付费）+存储包

按容量计费（按量付费）

按空间计费（包年包月）

说明

推荐购买存储包，更划算。详情请参见搭配存储包。

关于存储空间计费规则，请参见概览。

备份存储空间（仅超出免费额度时收费）

备份文件会占用一定的存储空间。PolarDB提供一定的免费空间额度，超过该额度的空间会产生费用。

备份文件产生的费用与容量和保存时长有关。

按量付费

说明

备份存储空间不支持包年包月计费。若您购买集群时选择包年包月，仅对计算节点的费用有效。因此，包年包月的集群依旧可能产生部分费用，例如备份存储空间产生的费用。推荐购买存储包，可抵扣其中一级备份的费用。详情请参见存储包规则。

关于数据备份的计费规则，请参见按量付费规则。

SQL洞察（可选）

SQL洞察为数据库提供安全审计、性能诊断等增值服务。开启后，审计日志存储会产生费用。

SQL洞察产生的费用与审计日志的存储容量和保存时长有关。

按量付费

说明

SQL洞察不支持包年包月计费。若您购买集群时选择包年包月，仅对计算节点的费用有效。因此，包年包月的集群依旧可能产生部分费用，例如SQL洞察产生的费用。

关于SQL洞察的计费规则，请参见SQL洞察计费规则（可选）。
