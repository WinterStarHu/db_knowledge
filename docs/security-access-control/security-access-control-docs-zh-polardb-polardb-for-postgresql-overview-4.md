产品详情 我的收藏

PolarDB是阿里巴巴自研的新一代云原生数据库。在计算存储分离架构下，利用了软硬件结合的优势，为您提供具备秒级弹性、高性能、海量存储、安全可靠的数据库服务。PolarDB PostgreSQL企业版100%兼容原生PostgreSQL的多个版本，包括PostgreSQL 11/14/15/16/17。基于Cloud Native设计理念，它既融合了商业数据库稳定可靠、高性能、可扩展的特征，又具有开源云数据库简单开放、快速迭代的优势。

PolarDB采用存储和计算分离的架构，所有计算节点共享一份数据，提供分钟级的配置升降级、秒级的故障恢复、全局数据一致性和免费的数据备份容灾服务。
基本概念

地域（Region） 数据中心所在的地理位置。

可用区（Zone） 可用区是指在某一地域内，具有独立电力和网络的物理区域。同一可用区内实例之间的网络延时更小。更多信息请参见阿里云全球基础设施。

集群 （Cluster）

一个集群中有一个主节点和多个只读节点。单个PolarDB集群支持跨可用区，但不能跨地域。

集群ID以pc开头。

节点（Node）

PolarDB集群由多个物理节点构成，每个集群中的节点可分为两类，每一类节点关系对等，规格相同。这两类节点分别叫主节点和只读节点。

节点ID以pi开头。

主节点（Primary node） PolarDB主节点，也叫读写节点，一个集群中只有一个主节点。

只读节点（Read-only node） PolarDB只读节点，企业版集群中最多可添加至15个只读节点，标准版集群中最多可添加至7个只读节点。
