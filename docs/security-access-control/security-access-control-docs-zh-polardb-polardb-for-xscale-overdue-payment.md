阿里云账号欠费后，该账号下所有PolarDB-X按量付费实例将会进入欠费状态。您可以在一定时间内解锁或重建实例。对于包年包月实例，开启自动续费后，直到下一个续费动作前不会受到影响。

警告 阿里云账号欠费后，实例有停机风险，系统会通知您，请及时充值，避免对您的业务造成影响。
实例欠费状态说明

状态 如何操作

阿里云账号欠费后，该账号下所有按量付费实例将会变成欠费状态。

欠费后，如果在延停权益额度内，您的实例将不会停机。在此期间，您每天会收到一次短信提醒。

说明 阿里云提供延期免停权益，即当按量付费的资源发生欠费后，提供一定额度或时长继续使用云服务的权益，延停期间正常计费。具体使用说明和规则，请参见延期免停权益。

超出延停额度后，阿里云会暂停该实例的服务（停机），并停止计费。实例将处于锁定状态，无法访问。
在锁定状态下，您可以给阿里云账号充值，充值后，实例将解除锁定状态并恢复正常。

PolarDB-X实例停机后第16天（即停机15天后），实例将被释放。
PolarDB-X实例释放后，不可恢复。

说明 PolarDB-X实例被释放后，其跨地域备份的数据会在保存时间内继续保留，您可以在新实例满足跨地域恢复的前提条件后酌情恢复数据。
