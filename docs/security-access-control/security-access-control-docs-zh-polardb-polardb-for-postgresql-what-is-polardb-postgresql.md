本文介绍了PolarDB PostgreSQL标准版的背景、特点、与企业版区别以及如何购买等内容。

什么是PolarDB PostgreSQL标准版 自PolarDB正式上线以来，它已成功支撑成千上万的客户应用，并在真实的商业环境中展现了卓越的表现。PolarDB凭借其卓越的性能、坚如磐石的稳定性和为企业度身定制的高级功能，为客户提供了前所未有的数据库体验。
在早期，PolarDB主要面向大型企业和有特定需求的客户，只推出了企业版。该版本建立在高度定制的物理机上，并搭载了阿里巴巴自主研发的分布式存储技术——PolarStore。这种配置确保了极致的性能和稳定性，产品的成本也相对较高。
随着技术的不断进步和市场需求的变化，PolarDB推出了性价比更具吸引力的产品版本--标准版。与企业版不同，标准版充分利用了云端规模化、标准化的计算和存储资源。更为关键的是，团队对其进行了深度的内核优化，使其既能保持高性能，又能大幅降低成本。这不仅为客户带来了更为优惠的价格，还通过与ECS、云盘等产品深度整合，为客户提供了更为丰富、灵活的计算和存储选项。标准版的架构如下所示： PolarDB PostgreSQL标准版实现了更高的性价比，使更多客户可以享受到云原生架构带来的极致性能、弹性、稳定性。
PolarDB PostgreSQL标准版与企业版的区别 PolarDB PostgreSQL企业版和标准版在核心架构和主要功能上保持高度一致，这意味着无论您选择哪一个版本，都能获得PolarDB的核心优势。在使用上，两者的差异为计算和存储层软硬件不同。

在计算层，企业版计算节点使用物理机，没有虚拟化开销；而标准版使用ECS服务器。

在存储层，企业版提供了PSL4和PSL5这两种性能配置选项。这两种选项的主要区别在于它们的性能指标，例如，IOPS（输入/输出操作每秒）和读写带宽。这些性能指标完全基于计算节点的规格，而与实际的存储容量没有直接关系。这种设计确保了企业版用户在任何存储量下都能获得一致、可预测的高性能。
而对于标准版，其存储方面的选择更为灵活。标准版采用了云端的标准云盘技术，并提供了PL0、PL1、PL2、PL3以及AutoPL等多种性能选项供用户选择。与企业版不同，这些选项的性能指标是随着存储容量的变化而变化。当数据量较小时，带宽会比较小（每GB对应约50 IOPS）；随着数据量增长，存储的性能也会相应地提高，为您的应用提供更为流畅的体验。
存储与数据可靠性 PolarDB PostgreSQL版的标准版采用共享存储架构，存储层使用ESSD云盘。ESSD云盘采用多副本的分布式机制，具有低延时、高性能、持久性、高可靠等特点。
ESSD云盘是阿里云全新推出的超高性能云盘产品。ESSD云盘基于新一代分布式块存储架构，结合25 GE网络和RDMA技术，为您提供单盘高达100万的随机读写能力和更低的单路时延能力。ESSD云盘分为如下几类：

ESSD PL0云盘：PL0性能级别的ESSD云盘。

ESSD PL1云盘：相比PL0，PL1性能级别的ESSD云盘可提升5倍IOPS，以及提升大约2倍的吞吐量。

ESSD PL2云盘：相比PL1，PL2性能级别的ESSD云盘大约可提升2倍IOPS和吞吐量。

ESSD PL3云盘：相比PL2，PL3性能级别的ESSD云盘最高可提升10倍IOPS、5倍吞吐量，适合对极限并发I/O性能要求极高、读写时延极稳定的业务场景。

ESSD AutoPL云盘：相比PL0、PL1、PL2和PL3，IOPS与容量解耦，可灵活配置，按需调整，从而降低整体TCO。
关于ESSD云盘的性能详情，请参见ESSD云盘。

重要 云盘的存储空间满载后，云盘会锁定（只读不写）。
数据可靠性 ESSD云盘采用分布式三副本机制，可以提供99.9999999%的数据可靠性保证。支持在可用区内自动复制您的数据，防止因意外硬件故障导致数据不可用问题，保护您的业务免于遭受组件故障的威胁。具体请参见ESSD 云盘数据可靠性。
如何购买或迁移到标准版集群

您可以在PolarDB的购买页，购买PolarDB PostgreSQL标准版。

如果您还不熟悉标准版，可以先尝试PolarDB免费试用版。

PolarDB还提供了从RDS迁移功能，您可以在购买新集群时，从RDS迁移到PolarDB，无需额外费用。

您可以通过DTS实现从自建PostgreSQL或RDS到PolarDB PostgreSQL版的在线迁移。

您可以使用开源社区提供的pg_dump、pg_restore工具进行离线迁移。
