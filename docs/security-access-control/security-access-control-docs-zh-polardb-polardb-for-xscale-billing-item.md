本文介绍PolarDB-X的计费项及各计费项的价格。

主实例规格

定义：PolarDB-X企业版主实例（计算节点规格单价*计算节点个数）+（存储节点规格单价*存储节点个数）整体费用；PolarDB-X标准版节点规格费用。

是否必选：是。

计费方式：包年包月或按量付费。关于计费方式的说明，请参见计费方式。

价格：购买实例的价格与所选地域、规格、存储等配置相关，请前往购买页面查看。

说明 存储空间费用计费方式选择按量付费时，包年包月实例会产生按量付费项。
只读例规格

定义：PolarDB-X企业版只读实例（计算节点规格单价*计算节点个数）+（存储节点规格单价*存储节点个数）整体费用。

说明 PolarDB-X标准版暂不支持只读实例。

是否必选：否。

计费方式：包年包月或按量付费。关于计费方式的说明，请参见计费方式。

价格：购买实例的价格与所选地域、规格、存储等配置相关，请前往购买页面查看。

说明 存储空间费用计费方式选择按量付费时，包年包月实例会产生按量付费项。
存储空间

定义：PolarDB-X实例（主实例、只读实例、GDN从集群）存储空间费用。

是否必选：是。

计费方式：按量付费或包年包月。

价格：请参见存储空间价格。
备份

定义：PolarDB-X实例自动备份和手动备份产生的备份文件存储占用空间的费用。

是否必选：

基础备份：是。

异地备份：否。

本地盘实例：实例实际存储空间的50%。

列存索引（Columnar）

定义：PolarDB-X企业版用于分析查询加速的数据传输的增值服务。

是否必选：否。

计费方式（拟）：包年包月或按量付费。

价格：公测阶段，免费使用。

说明 列存索引功能免费使用，索引存储费用由对象存储（OSS）收取。
全局数据库网络（GDN）

定义：PolarDB-X企业版提供的跨Region本地读取和容灾切换的增值服务。

是否必选：否。

计费方式：包年包月或按量付费。

价格：

实例规格与存储：购买实例的价格与所选地域、规格、存储等配置相关，请前往购买页面查看。

跨Region网络流量：免费。
冷数据归档

定义：PolarDB-X企业版提供的一项增值服务，通过按设定的时间策略自动归档冷数据，在大幅降低存储成本的同时，确保所有数据仍可通过SQL在线查询。

是否必选：否。

计费方式：按存储使用量。

价格：0.000167元/GB/小时。
外网流量

定义：通过外网地址连接PolarDB-X实例所产生的公网入流量和出流量。

是否必选：否。

计费方式：免费。

说明：申请外网地址本身不收费，通过外网地址连接实例所产生的公网入流量和出流量均免费。您可在控制台申请外网地址后，通过该地址从本地或其他非 ECS 环境连接数据库，无需支付额外的网络费用。
