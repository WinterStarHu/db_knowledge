通过阅读本文，您可以快速了解云原生数据库PolarDB的计费类型、计费项、资源包、到期或欠费、续费等主要计费信息。

云原生数据库PolarDB采用计算存储分离架构。在使用PolarDB集群时，计算节点与存储空间将分别计费。同时，云原生数据库PolarDB还为您提供资源包，以帮助您降低使用成本。

计费类型 云原生数据库PolarDB提供三种计费类型，包括包年包月、按量付费和Serverless，以满足您在不同场景中的需求。详细说明请参见计费类型。

包年包月：预付费模式。在创建集群时，您需选择固定规格的资源，并预先支付集群的费用。购买周期越长，所享受的折扣也越大。该模式一般适用于业务需求长期稳定的场景。

按量付费：后付费模式。在创建集群时，您需选择固定规格的资源，但无需提前支付集群的费用。该模式根据您实际使用的时长进行计费，一般适用于业务需求灵活的场景。

Serverless：后付费模式。在创建集群时，您无需选择固定规格的资源，也无需提前支付集群的费用。该模式是指PolarDB集群的动态弹性扩缩容能力，能够根据系统业务负载的变化进行调整。一般适用于业务波动、不确定负载或不可预测的业务场景。
在使用PolarDB集群时，如果您发现当前集群的付费类型无法满足您的业务需求，您可以根据实际需求随时转换付费类型。

计费项 云原生数据库PolarDB的计费项由计算节点、存储空间、备份存储（超出免费额度）、SQL洞察（可选）和冷数据归档（可选）组成。详细说明，请参见计费项总览。

资源包 云原生数据库PolarDB为您提供固定规格计算包、Serverless计算包和存储包三种类型资源包，助您降低PolarDB的使用成本。详细说明，请参见资源包选型指南。

费用账单 您可以在费用与成本 > 账单 > 账单详情查看云原生数据库PolarDB相关的账单及用量明细，以便深入了解您的费用状况。详细说明，请参见费用账单。

到期或欠费 在您的PolarDB集群到期或阿里云账号出现欠费的情况下，将会影响PolarDB集群的正常运行。因此，您需要及时进行续费或充值。详细说明，请参见到期或欠费说明。

续费 云原生数据库PolarDB为您提供自动续费和手动续费两种续费方式。详细说明，请参见续费说明。

说明 包年包月集群在到期后将会影响PolarDB集群的正常运行。如需继续使用PolarDB集群，请及时进行续费。

退订 包年包月集群和资源包均支持退订。当您不再需要使用时，可以进行退订，以避免产生持续费用。详细说明，请参见退订说明。
