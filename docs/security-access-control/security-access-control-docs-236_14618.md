Last updated: 2026-08-26 09:46:20 AI-Translated Yearly/monthly subscription prepaid: For TencentDB for MySQL return and refund requests, a non-full refund will be processed.
Pay-as-you-go postpaid: Resources are released after a TencentDB for MySQL return request is submitted. Since fees are charged based on your actual resource usage during settlement, no refund is involved.
Both yearly/monthly subscription and pay-as-you-go instances can be returned in the instance list of the TencentDB for MySQL console.
Note:
If a terminated or returned yearly/monthly subscription instance is restored from the recycle bin, it cannot be terminated or returned again within 30 minutes. If you need to terminate or return the instance, perform the operation 30 minutes after it has been restored.
Self-Service Return Instructions After a yearly/monthly subscription instance is returned via self-service, no fees related to the instance will be incurred once its status changes to Isolated.
After a yearly/monthly subscription instance is completely terminated, its IP address is released and the instance becomes inaccessible. If the instance has associated read-only or disaster recovery instances:
The read-only instances will also be terminated.
The disaster recovery instance will disconnect the synchronization connection and automatically upgrade to the primary instance.
After a yearly/monthly subscription instance is returned via self-service, the instance is moved to the cloud database recycle bin and retained for 7 days, during which it is inaccessible. If you want to restore a returned yearly/monthly subscription instance, you can renew and restore it in the cloud database recycle bin.
After a pay-as-you-go instance is returned, it is moved to the cloud database recycle bin and retained for 24 hours, during which it is inaccessible. If you want to restore the instance, you can start it up in the recycle bin.
In case of suspected abnormal or malicious returns, Tencent Cloud reserves the right to reject your return request.
Self-service return is not supported by some event resources. See the official website for details.
Standard Self-Service Refund In the common self-service return mode, the fees for your used bandwidth will also be deducted, and the refund amount will be returned to your Tencent Cloud account based on the proportion of cash and free credits used for the purchase.
Common Self-Service Return Rules Refund amount = Current effective order amount + Unstarted order amount – Used resource value Current effective order amount: Refers to the payment amount of orders in effect, excluding discounts and vouchers.
Unstarted order amount: The payment amount for future-effective orders, excluding promo vouchers.
The value of used resources shall be calculated according to the following policies:
For the used portion, full months prior to the refund request date are deducted at the monthly rate, while any remaining period less than a full month is deducted at pay-as-you-go rates.
The used portion is calculated precisely to the second.
If the refund amount is less than or equal to 0, it will be calculated as 0, and the resources will be reclaimed.
Note:
Discounts or vouchers are non-refundable.
The refund amount will be returned to your Tencent Cloud account based on the proportion of cash and free credits used for the purchase.
