PolarDB分布式轻量版控制台提供国产轻量化授权订单的管理功能，支持根据订单分批创建授权。

重要

目前仅支持PolarDB分布式轻量版基础版（不带管控）订单，暂不支持PolarDB分布式轻量版高级版（带管控）订单。

地域需设置为华东1（杭州），否则下载安装包或者授权文件的界面会有异常。
创建授权

登录PolarDB分布式版控制台。

在页面左上角选择华东1（杭州）地域。

左侧导航栏，单击国产轻量化。

选择目标订单，在操作列单击创建。

在创建授权面板，按需填入如下参数：

填写项目 是否必填 描述

订单号 是 选择的订单号，已经自动填充。

名称 是 授权的名称，方便标识和管理。

描述 否 该授权信息的描述信息。

MAC地址 是

多个MAC地址使用英文逗号分隔，例如：xx:xx:xx:xx:xx:xx,xx:xx:xx:xx:xx:xx。

支持上传本地文件配置MAC地址。

端口范围 是 只有计费类型为实例的时候，才需要填该项。

字符最大长度为255，只包含字符0～9及-。

输入单个端口或者端口范围，多个使用逗号分隔，端口大小满足 0～65535。

示例： 3306,4000-5000,7000。

填写完成，点击确定发起创建。可以在创建历史里查看创建状态，预计1分钟内可以创建完成。

单击确定，即可完成创建。

说明 创建授权完成后，您可以查看授权历史。
