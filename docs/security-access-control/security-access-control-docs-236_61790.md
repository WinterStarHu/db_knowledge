Description The billing cycle for the database proxy service starts when the instance's database proxy is activated and ends when the database proxy is deactivated. If the database proxy is not deactivated after being activated, the billing cycle lasts from the database proxy activation to the instance's destruction/decommissioning.
When does the database proxy start billing?
Billing starts immediately when your TencentDB for MySQL instance activates the database proxy if it does not meet the New Customer Discount Strategy. The New Customer Discount Strategy stipulates that users who have not activated the database proxy before the official commercial billing time (16:00:00 Beijing Time on April 1, 2024) can enjoy a 15-day free trial of the database proxy feature for up to three instances under one Tencent Cloud UIN account. Each instance is entitled to a discount of up to 32 cores and 64,000MB total for its database proxy nodes. After the free trial ends, if you do not need to use the database proxy, you can deactivate it. If you wish to continue using the database proxy, the instance's database proxy will be billed normally by usage. For more details, please refer to New Customer Discount Strategy.
When does the database proxy stop being billed?
The database proxy stops being billed under the following circumstances:
The instance with an activated database proxy deactivates the database proxy. In this case, billing for the database proxy will cease immediately.
When an instance with an activated database proxy is destroyed/decommissioned and enters isolation, billing for the database proxy will cease immediately.
The lifecycle of an annual and yearly/monthly subscription instance allows access for up to seven days after expiration. After seven days, the instance enters isolation, and after another seven days, it is decommissioned. If the billing model is annual and yearly/monthly subscription and the instance with an activated database proxy expires, the database proxy will continue to be billed during the seven days in which the instance can still be accessed. Once the instance enters the isolation state after these seven days, billing for the database proxy will cease.
