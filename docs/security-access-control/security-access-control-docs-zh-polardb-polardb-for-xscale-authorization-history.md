产品详情 我的收藏

PolarDB分布式轻量版控制台提供国产轻量化授权订单的管理功能，支持根据订单分批创建授权。

重要

目前仅支持PolarDB分布式轻量版基础版（不带管控）订单，暂不支持PolarDB分布式轻量版高级版（带管控）订单。

地域需设置为华东1（杭州），否则下载安装包或者授权文件的界面会有异常。
操作步骤

登录PolarDB分布式版控制台。

在页面左上角选择华东1（杭州）地域。

左侧导航栏，单击国产轻量化。

选择目标订单，在操作列单击历史，参数说明如下：

项目 描述

时间 创建授权时的时间戳。

项目编号 项目编号，例如：pj-xxxxxxxx。

名称 授权名称。

描述 授权描述。

MAC地址 创建时输入的MAC地址。

端口范围 只有计费类型为实例的时候，才会显示该项。

状态 授权进程的状态，有以下3种状态：

创建中：授权正在创建中。

完成：授权已完成。

失败：授权失败。

操作 支持以下三种操作：

修改：支持修改授权的名称和描述。

下载RPM包：跳转到部署包管理页面，可下载RPM安装包。

下载授权：跳转到授权管理页面，可下载授权码。
