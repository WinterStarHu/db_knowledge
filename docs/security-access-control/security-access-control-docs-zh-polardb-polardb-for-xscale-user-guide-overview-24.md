本文主要介绍PolarDB-X 1.0的数据库详情。

概念上，PolarDB-X 1.0数据库类似MySQL和Oracle中的数据库。

使用上，PolarDB-X 1.0提供一个完整的数据库使用接口，业务应用程序直接连接至PolarDB-X 1.0数据库，与使用单机数据库效果一致。

物理存储上，PolarDB-X 1.0底层存储由一个或者多个私有定制RDS实例组成，一个PolarDB-X 1.0数据库由底层一个或多个私有定制RDS实例所提供的数据库组成。

针对单个实例，数据库管理包括创建数据库、查看数据库详情、配置读写分离、数据表管理、分库管理、白名单设置、数据导入、只读实例管理、平滑扩容、查看监控信息等功能。
