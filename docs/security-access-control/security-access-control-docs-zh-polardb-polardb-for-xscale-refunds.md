退款说明 根据计费方式的特点，PolarDB-X支持的退款情况如下表所示。

计费方式 退款说明

包年包月 当您购买包年包月PolarDB-X实例时需要根据购买时长预先支付费用。如果您业务调整不再需要使用包年包月实例，可申请退款。退款前，请充分了解阿里云产品退订规则，然后登录退订管理页面进行退订操作。退款时，系统会根据您实例的使用情况进行结算。

按量付费 按量付费的PolarDB-X实例会根据实际使用情况实时产生账单，因此不涉及退款。如果您不再需要使用上述实例，可以在确保已备份或迁移数据，且不影响您业务的同时选择释放PolarDB-X实例。实例被释放后将不再进行计费。
此外，您还需要注意：

PolarDB-X的按量付费项目支持搭配PolarDB-X存储资源使用，不同种类的优惠方案支持以折扣价格抵扣相应的按量付费项目。此类优惠方案原则上均不支持退款。

以下涉及转换计费方式、实例降配的场景中，也可能涉及退款。您可以根据实际情况了解相关说明文档。

场景 说明

转换计费方式 PolarDB-X包年包月转按量之后，会将包年包月实例的剩余预付款项以退订金额返还给您。退订金额计算公式： 退订金额 = 订单实付金额 - 已消费金额

降配包年包月实例 对包年包月实例进行降配或减少节点数之后，会将新老配置的差价以退订金额的形式退还给您。退订金额计算公式： 退订金额 = 订单实付金额 - 已消费金额

取消续费 对包年包月实例进行续费之后，在该续费订单生效之前，如果执行退订操作，则续费的金额会全额退还给您。更多信息，请参见退订规则的退订续费周期章节。
