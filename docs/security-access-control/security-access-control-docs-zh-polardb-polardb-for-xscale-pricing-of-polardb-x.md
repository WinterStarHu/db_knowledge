PolarDB-X一体化实例由多个逻辑节点构成，部署多个节点进行水平扩展，每个节点闭环整合计算资源与存储资源，运维管理更加便利。本文主要介绍PolarDB-X产品如何计费。

计费方式 PolarDB-X支持包年包月和按量付费两种计费方式。
包年包月（预付费）

定义：包年包月也称为预付费，即在新建实例时支付费用。

适用场景：计划长期使用实例，折扣力度随购买时长增加而增大。

计费方式转换：包年包月可以变更为按量付费。

变更配置：包年包月实例变更配置时会产生补差价或者退款。详情请参见变更配置。

续费：包年包月实例到期后将无法正常运行。如果您想继续使用实例，需要在指定时间内为实例续费，否则CPU、内存、磁盘存储等所有实例占用资源会自动释放。续费相关的更多信息，请参见续费说明。

说明 不支持续费变配。
按量付费（后付费）

定义：按量付费实例开通时不会进行扣费，创建开始运行后，阿里云每小时（不足1小时按1小时计费）自动按照实例资源消耗和使用量从账号中扣除相关费用。

适用场景：适合1个月以内的临时使用需求，使用结束后可立即释放实例。

计费方式转换：按量付费可以变更为包年包月。

变更配置：按量付费实例按每小时收费，变更配置后按照新的售价每小时收费。详情请参见变更配置。

欠费：阿里云账号欠费后，该账号下所有非包年包月实例将会变成欠费状态。关于欠费的更多信息，请参见欠费说明。
计费组成 PolarDB-X实例的基础费用由计算节点资源费用、存储节点资源费用和数据存储资源费用组成，相同实例中计算节点和存储节点的计费方式相同。
