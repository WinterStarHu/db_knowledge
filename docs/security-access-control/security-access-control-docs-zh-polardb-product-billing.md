本文为您介绍云原生数据库PolarDB的计费方式及计费组成等信息。
计费方式 包年包月（预付费）

定义：包年包月也称为预付费，即在新建集群时需支付费用。

适用场景：计划长期使用集群，折扣力度随购买时长增加而增大。

计费方式转换：包年包月可以变更为按量付费。详情请参见PolarDB MySQL版包年包月转按量付费、PolarDB PostgreSQL版包年包月转按量付费、PolarDB PostgreSQL版包年包月转按量付费

变更配置：包年包月集群变更配置时会产生补差价或者退款。详情请参见变更配置。

续费：包年包月集群到期后将无法正常运行。如果您想继续使用集群，需要在指定时间内为集群续费，否则CPU、内存、磁盘存储等所有集群占用资源会自动释放。详情请参见续费说明。

说明 PolarDB分布式版不支持续费变配。
按量付费（后付费）

定义：按量付费也称为后付费，即在新建集群时无需支付费用。创建开始运行后，阿里云每小时自动按照集群资源消耗和使用量从账号中扣除相关费用。

说明 阿里云账号的余额需要大于或等于100元，否则无法购买按量付费的集群。

适用场景：适合一个月以内的临时使用需求，使用结束后可立即释放集群。

计费方式转换：按量付费可以变更为包年包月。详情请参见PolarDB MySQL版按量付费转包年包月、PolarDB PostgreSQL版按量付费转包年包月、PolarDB PostgreSQL版（兼容Oracle）按量付费转包年包月

变更配置：按量付费集群按每小时收费，变更配置后按照新的售价每小时收费。详情请参见变更配置。

欠费：阿里云账号欠费后，该账号下所有非包年包月集群将会变成欠费状态。关于欠费的更多信息，请参见欠费说明。
Serverless

定义：Serverless是一种动态计费方式，可根据集群负载情况动态匹配资源，并实时计费，您仅需要为实际用量付费，节省大量成本。详情请参见PolarDB MySQL版Serverless集群、PolarDB PostgreSQL版Serverless集群。

适用场景：业务具有间歇性定时任务，负载有波动或不可预测。

变更配置：Serverless集群会在PCU弹性扩缩容的范围内根据实际业务压力自动增加或减少PCU，实时计费。

欠费：阿里云账号欠费后，该账号下所有非包年包月集群将会变成欠费状态。关于欠费的更多信息，请参见欠费说明。
