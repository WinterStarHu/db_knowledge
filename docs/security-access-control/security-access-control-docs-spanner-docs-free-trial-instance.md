为什么我无法在项目中创建免费试用实例？
您可以为每个项目创建一个免费试用实例。如果您已在项目中创建免费试用实例，则无法再创建其他实例。
为什么我无法在实例配置 X 中创建免费试用实例？
所有区域级配置均提供 Spanner 免费试用实例。它们不适用于双区域或多区域配置。如何在免费试用实例中创建超过 5 个数据库？
如果您想创建超过 5 个数据库，请将免费试用实例升级为付费实例。我的免费试用实例已被停用。如何重新启用该功能？
如果您已完成 Spanner 90 天的免费试用期，则免费试用实例会被停用并进入 30 天的宽限期。您可以在 90 天的试用期或 30 天的宽限期内将免费试用实例升级为付费实例，以便重新开始使用实例。
