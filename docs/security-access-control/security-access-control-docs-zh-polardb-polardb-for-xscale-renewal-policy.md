包年包月实例到期后将无法正常运行。如果您想继续使用实例，需要在指定时间内为实例续费，否则CPU、内存、磁盘等资源会自动释放，数据将会丢失。PolarDB-X按量付费实例不涉及到期和续费。

警告 实例到期后有停机风险，系统会通知您，请及时续费，避免对您的业务造成影响。
续费方式 您可以通过自动和手动两种方式为实例续费，保证数据不丢失。实例续费费用与新购实例相同。
自动续费 PolarDB-X提供自动续费功能。
开通自动续费后，系统将在实例到期前第9天的08:00开始扣费。若未扣费成功，系统将在接下来的2天每天尝试扣费，最多尝试扣费3次。请保证阿里云账号的余额充足，避免自动续费失败。

重要 如果3次自动扣费均失败，请您及时手动续费，避免停机进而导致数据丢失。
手动续费 实例到期后，您可以在实例被释放前进行手动续费，费用将在续费时即时扣除。
实例到期状态说明

实例状态 如何操作

实例到期后，实例处于停机锁定状态，无法被访问。

实例停机15天后，实例被释放，除异地数据备份外，基础备份被删除。
实例锁定时，给实例手动续费，实例立即恢复正常。

重要 数据被释放后，无法找回。
