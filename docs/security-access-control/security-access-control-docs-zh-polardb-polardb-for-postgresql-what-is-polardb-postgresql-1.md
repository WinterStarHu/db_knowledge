PolarDB PostgreSQL分布式版集群是一款基于集中式PolarDB PostgreSQL版集群打造的分布式数据库，采用CN/DN的双层架构，实现计算与存储分离的分布式扩展能力。同时支持集中式PolarDB PostgreSQL版集群的现有能力，充分满足企业级业务在性能和可靠性方面的多样化需求。

什么是PolarDB PostgreSQL分布式版 自PolarDB正式上线以来，它已成功支撑成千上万的客户应用，并在真实的商业环境中展现了卓越的表现。PolarDB凭借其卓越的性能、坚如磐石的稳定性和为企业度身定制的高级功能，为客户提供了前所未有的数据库体验。
在智能驾驶训练、SAAS多租和区块链等场景中，由于数据规模不断膨胀，传统的集中式数据库已无法满足客户对业务持续增长的需求。针对市场需求的变化，PolarDB推出了PolarDB PostgreSQL分布式版集群，基于集中式PolarDB PostgreSQL版集群，采用CN/DN的双层架构，实现计算与存储分离的分布式扩展能力。同时支持集中式PolarDB PostgreSQL版集群的现有能力，充分满足企业级业务在性能和可靠性方面的多样化需求。PolarDB PostgreSQL分布式版架构如下： PolarDB PostgreSQL分布式版集群通过分布式扩展实现分布式特性，具备以下具体特征：

由CN/DN两类节点组成。其中，CN节点为计算节点，负责集群元数据管理和分布式计划制定。DN节点为数据节点，负责实际数据分片的存储。

每个CN/DN均采用存算分离架构的集中式架构，支持数据库代理与一写多读模式，具备CN/DN内计算节点的高可用切换功能，同时支持增加只读节点（RO）以扩展单个CN/DN的读能力。

支持手动分片，具备横向自由扩展能力，主要针对PB级以下的业务场景。

支持分布式事务的一致性。

支持双可用区部署，其中，主可用区为工作集群，备可用区为热备集群。

提供7x24小时不停机的变配升级维护能力，支持在集群中添加异构的CN/DN节点。
产品优势

集中式和分布式一体化 单个CN/DN既能作为分布式集群的一部分，又能独立提供集中式集群服务。每个CN/DN采用集中式架构，充分利用PolarDB的存算分离架构，发挥集中式集群的优势（如一写多读扩展、透明压缩及插件支持）。

易用性 提供统一的分布式视角，跨节点运维操作可在统一界面下完成，提升易用性。

费用说明 PolarDB PostgreSQL分布式版集群的费用包括计算资源费用、存储容量费用和SQL洞察（可选）费用。具体请参见分布式版产品计费。
