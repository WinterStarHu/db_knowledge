PolarDB MySQL版提供了多种产品类型以适应不同的业务场景。您可以通过本文了解不同产品类型之间的区别，在产品选型表中对比不同类型的参数，从而帮助您进行快速选型。

选型概述 在您根据自身业务场景选择PolarDB MySQL版产品时，您需要重点考虑以下关键因素：

内核版本

如果您已有自建MySQL数据库，希望迁移上云，建议您保持内核版本不变。

如果您需要新建数据库，推荐选择MySQL 8.0.1和8.0.2版本。

8.0.1完全兼容对应社区MySQL-8.0.13及更低的版本。

8.0.2完全兼容对应社区MySQL-8.0.18及更低的版本。

负载波动

如果您的业务负载是偶发性波动或剧烈波动的，建议您选择Serverless（非固定规格，性能随业务负载变化）。

如果您的业务较为平稳，建议您根据实际情况选择包年包月或按量付费（固定规格）。

业务规模

如果您追求高性价比的计算与存储资源，建议您选择标准版集群，其单个计算节点架构可以满足个人学习与测试的需求，多节点架构可以支持中大型企业的数据管理。

如果您追求更高的计算与存储性能、更好的功能体验和跨地域容灾保障，建议您选择企业版集群。

如果您的业务对并发写性能要求较高，建议您选择企业版集群中多主集群（Limitless）系列，其支持多主架构，满足高并发读写场景需求。
通过考虑内核版本、负载波动、业务规模等因素，您可以快速确定符合您业务需求的产品类型。如需了解对应类型的详细参数与说明，您可以参考概念说明与产品选型表。
