一个PolarDB-X实例是由多个节点组成的分布式集群。单个节点承担了SQL路由、数据合并、聚合等功能。通过实例变配，您可以变更实例的节点规格和存储空间，在业务繁忙时进行升配，承载更多的业务流量QPS，在业务空闲时进行降配，避免资源浪费。

变配方式 实例变配包含升配和降配两种方式，每种方式均支持节点规格变更和存储空间调整。

升配：升级CN节点（计算节点）和DN节点（存储节点）的规格，以及存储空间扩容（增加存储容量）。升配后实例可承载更多业务流量。

降配：降低CN节点（计算节点）和DN节点（存储节点）的规格，以及存储空间缩容（减少存储容量）。降配可节省资源成本。
注意事项

变配过程中由于应用与实例连接会中断，可能在短时间内会产生闪断 ，请确保应用程序具备重连机制。

使用长连接时，升配后新增节点无法立即接收到流量，建议灰度重启ECS服务器（即先重启拥有少量业务服务的ECS，观察业务情况，确认没问题后，再重启其他所有ECS）。如果使用Druid作为链接池，可以参考长链接的最佳实践，请参见如何选择应用端连接池。
操作步骤

登录PolarDB分布式版控制台。

在页面左上角选择目标实例所在地域。

在实例列表页，单击PolarDB-X 2.0页签。

在目标实例右侧的操作栏中，单击升配或降配。

在变配或降配页面：

选择目标节点规格与是否变更存储容量。

说明 企业版实例可以对计算节点和存储节点进行变配或降配，标准版实例只能对存储节点进行变配或降配。

选择切换模式。您可以实际业务场景选择立即执行或在维护时间内执行。

确认信息无误后，单击立即购买。返回在控制台，即可查看到实例状态为变配中（如选择立即执行）。
