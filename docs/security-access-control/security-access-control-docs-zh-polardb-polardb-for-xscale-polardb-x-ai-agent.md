产品详情 我的收藏

PolarDB-X AI助手是云原生数据库PolarDB分布式版推出的智能运维辅助工具，基于大语言模型与分布式数据库专家知识库，集成智能问答、智能诊断、智能巡检、Skill调用四大核心能力。AI助手支持自然语言交互，深度理解PolarDB-X的分布式架构，能够对多节点性能问题进行根因诊断，提供分片优化、SQL路由分析与弹性扩缩容建议。基于RAM访问控制，在智能化运维的同时确保实例和数据的安全性，能够显著降低分布式数据库的使用门槛和运维复杂度，助力您实现高效的问题排查与规模化集群管理。

核心能力

智能问答 基于自然语言输入，查询多实例数据、拓扑信息与性能指标，实现跨实例批量检索与问题诊断。同时提供资源评估、计费咨询、最佳实践指导等问答服务。
智能诊断 在慢SQL、锁分析、性能趋势等页面集成AI助手入口，结合分布式执行计划与上下文，实现即时的根因诊断与优化建议。
智能巡检 支持对账号下的实例进行一键健康巡检，运维状态、备份配置、安全设置和高可用容灾能力，快速发现潜在风险和配置问题。
Skill调用集成 支持通过Skill调用方式接入AI编程助手与IDE环境，在开发工作流中直接调用分布式数据库智能运维能力，无需切换到控制台。
快速访问AI助手

您可以登录PolarDB分布式版控制台，在实例列表中单击页面最右侧边栏图标进入对话界面。

更多入口：PolarDB-X还将AI助手深入嵌入至各功能界面：

功能入口 示例

慢SQL：您可以在目标实例的诊断与优化 > 慢日志中，对指定范围内的慢SQL进行分析。
在慢日志页面中，可单击PolarDB-X AI分析页签，对慢 SQL 进行智能分析。

锁分析：您可以在目标实例的诊断与优化 > 锁分析中，对指定范围内的死锁进行分析。
在该页面中，单击立即诊断可发起死锁诊断，单击PolarDB-X AI分析可使用 AI 辅助分析死锁问题。

性能趋势：您可以在目标实例的诊断与优化 > 性能趋势中，对指定范围内的CPU利用率、内存利用率、活跃会话连接或请求响应时间等进行分析。
在页面顶部可选择计算节点或数据节点页签，指定节点类型与数据粒度（如5秒），并单击右侧PolarDB-X AI分析按钮发起智能分析。

说明 RAM子账号访问时需确保已具备PolarDB-X只读权限（AliyunDRDSReadOnlyAccess）与AliyunYaoChiAgentAccess。授权方法，请参见为RAM用户授权。

技能领域 核心能力 典型场景

故障诊断 根因定位与事件分析 日志诊断（错误日志/慢查询）、连接与会话异常排查，快速定位问题根因并评估影响。

性能优化 实例性能诊断 监控CPU/内存/存储/IOPS资源水位，分析性能瓶颈，识别慢SQL并提供优化建议。

容量管理 存储与资源规划 分析存储空间使用趋势和增长预测，评估资源扩容需求，避免容量不足的风险。

风险治理 版本安全与风险预警

识别内核版本高危漏洞，评估升级紧迫性。

检查实例运行状态、版本与付费异常，提前预警。

备份恢复 备份策略与容灾评估

评估备份策略有效性与执行成功率。

检查实例高可用配置和容灾能力，保障业务连续性。

安全合规 访问控制与审计 核查IP白名单配置、账号权限配置、SSL/TDE加密状态、审计日志完整性，确保安全合规。

资产管控 实例生命周期管理 多维度实例筛选与查询、包年包月到期提醒、实例状态全景监控，实现精细化资产管理。

实例巡检 全栈健康检查 自动化巡检实例配置、性能基线、安全策略与备份状态，生成巡检报告并推送整改建议。
智能问答 智能问答功能允许您通过自然语言快速查询实例信息与咨询产品技术知识。AI助手能够帮助您理解PolarDB-X的分布式架构，以及对CN/DN节点等概念具备专业认知。
适用场景

全域资源查询：批量查询实例配置、拓扑结构、分片规则与性能指标。

异常实例筛查：识别DN、CN连接数异常、分片热点与存储倾斜等风险实例。

分片与拓扑查询：查询分库分表规则、数据分布情况与全局二级索引状态。

合规与治理检查：查询安全策略（如SQL审计开启、IP白名单配置或SSL加密状态）。

产品与技术咨询：获取PolarDB-X的功能说明、版本特性与分布式最佳实践。
快速上手 通过简单的提问，PolarDB-X AI助手可以帮助您快速获取实例的配置、拓扑结构、数据分布和性能指标等，无需您手动查找。

支持查询的信息维度

实例属性：实例ID、版本、规格、状态、CN/DN节点数量、存储类型、VPC与网络信息。

拓扑结构：CN节点列表与状态、DN节点列表与状态、GMS节点信息与读写分离配置。

数据分布：分库分表规则、分片键信息、数据分布、全局二级索引状态。

计费与成本：计费类型、到期时间、各节点规格与费用构成。

监控指标：批量查看各节点CPU使用率、IOPS、QPS/TPS与连接数。

智能诊断 AI助手的智能诊断基于AI大模型，为分布式数据库提供全方位的自动化诊断与优化能力。您可以通过AI助手对实例运行状态、慢SQL、存储空间等场景进行深度分析，快速定位问题根因并获取可执行的优化建议。
适用场景

慢SQL诊断：分析分布式查询的执行计划，自动识别全表扫描、跨分片Join、数据倾斜等典型性能问题，并提供索引优化和分片键调整建议。

CPU/内存/IO性能问题排查：当实例出现CPU飙升、内存占用异常或IO瓶颈时，AI助手可结合监控指标和运行日志定位资源热点，给出针对性的调优方案。
快速上手

实例异常分析：支持CPU飙升、存储空间增长、DN节点异常、分布式事务超时以及慢查询等场景分析。

性能优化：当CPU、内存或IOPS出现异常波动时，将分析资源热点并给出针对性的调优方案。

容量管理：对存储空间的使用趋势进行分析，获取增长预测和扩容时间窗口建议。
智能巡检 巡检覆盖项 巡检报告将涵盖以下维度：

实例状态：主实例状态、只读实例/子实例状态、关联实例状态、DN磁盘用量水位、运维任务执行窗口。

备份状态：备份策略配置（类型、周期、保留时长）、备份集列表有效性（最近备份时间、成功率）、跨地域备份开启情况。

安全配置：IP白名单访问控制、账号三权分立、SSL加密传输、TDE透明存储加密、SQL审计与洞察。

高可用与容灾：CN可用区分布、DN多副本分布 (Leader、Follower、Logger)、整体跨可用区容灾能力评估。

注意事项

提问精准：提问时建议在@选择实例ID、地域（Region）、时间范围及问题现象描述。对于分布式场景，可指定具体的DN节点或数据库名称以获取更精准的诊断。

上下文对话：AI助手支持多轮对话，可基于前一轮的诊断结果进行追问。但涉及敏感操作（例如分片规则变更建议）时，请谨慎评估后再执行。

诊断时效性：性能诊断依赖监控数据，建议在问题发生后尽快发起分析，以确保相关指标数据仍在保留期内。如遇卡顿请退出会话重新提问。

决策审慎：所有优化建议仅供参考，特别是分布式架构下的变更操作，请在充分测试和评估后再执行。
安全与合规

数据访问范围：为提供准确的诊断和问答服务，PolarDB-X AI助手会访问实例元数据、拓扑信息、性能监控指标、慢日志关键信息及您输入的问题。AI助手不会执行任何DDL或DML语句，不会直接修改实例配置或触发数据搬迁。

权限控制：AI助手严格继承RAM权限体系，只读类操作直接执行，任何涉及变更的操作建议均需您手动确认后执行。

数据隐私：您的查询历史和实例数据严格遵守阿里云隐私政策，不会被用于模型训练或发送给第三方。

责任声明：AI助手提供的诊断结论和优化建议仅供参考。在生产环境执行变更前（特别是涉及分片规则调整、全局索引变更等分布式操作），需由专业DBA或技术人员审查评估。
