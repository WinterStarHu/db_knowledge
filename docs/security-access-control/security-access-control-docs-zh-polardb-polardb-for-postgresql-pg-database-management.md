本文为您介绍如何创建与管理PolarDB PostgreSQL版集群内的数据库。

创建数据库

前往PolarDB控制台，在目标集群的左侧导航栏中，选择配置与管理 > 数据库管理。

单击创建数据库，并设置以下参数，确认无误后，单击确定创建数据库。

参数

说明

数据库(DB)名称

数据库名称。要求如下：

以字母开头，字母或数字结尾。

长度为2～64个字符。

由小写字母、数字、中划线（-）或下划线（_）组成。

说明

数据库（DB）名称在集群内需保持唯一性。

数据库（DB）名称一旦创建，便不再支持修改，请谨慎填写。

请勿使用保留关键字作为数据库名称，如test等。

数据库Owner

数据库的所有者，对数据库拥有ALL权限。本参数可以留空，您可在创建数据库后，再修改数据库Owner。

支持字符集

数据库支持的字符集，默认为UTF8。 如果需要其他字符集，请在下拉列表中选择需要的字符集。

Collate

字符串排序规则，默认为C。如果您有使用小语种的需求，建议选择en_US.utf8。

Ctype

字符分类，根据上述字符串排序规则进行联动选择。

备注说明

用于备注该数据库的相关信息，便于后续数据库管理。要求如下：

不能以http://或https://开头。

长度为2～256个字符。

由大小写字母、中文、数字、下划线（_）或中划线（-）组成。

删除数据库

警告

删除数据库后，将会清除数据库内所有数据，并且该数据库将无法再进行访问。因此，请谨慎操作。

前往PolarDB控制台，在目标集群的左侧导航栏中，选择配置与管理 > 数据库管理。

找到目标数据库，单击操作栏中的删除。确认无误后，单击确定删除数据库。

修改数据库Owner

前往PolarDB控制台，在目标集群的左侧导航栏中，选择配置与管理 > 数据库管理。

找到目标数据库，单击操作栏中的修改Owner。

在修改Owner弹窗中，选择目标数据库的所有者，并单击确定。
