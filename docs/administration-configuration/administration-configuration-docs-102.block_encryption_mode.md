block_encryption_mode ==========================================

`block_encryption_mode` 用于指定在函数 aes_encrypt 和 aes_decrypt 中使用的加密算法。

| **属性**  |                                                                                                                                                                                                                                                                                                                                                                                                                                                                       **描述**                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
|---------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 参数类型    | enum                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| 默认值     | aes-128-ecb                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| 取值范围    | aes-128-ecbaes-192-ecbaes-256-ecbaes-128-cbcaes-192-cbcaes-256-cbcaes-128-cfb1aes-192-cfb1aes-256-cfb1aes-128-cfb8aes-192-cfb8aes-256-cfb8aes-128-cfb128aes-192-cfb128aes-256-cfb128aes-128-ofbaes-192-ofbaes-256-ofb    |
| 生效范围    | GlobalSession                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| 是否参与序列化 | 是                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
