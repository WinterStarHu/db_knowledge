# 关键字

SQL里有保留字和非保留字之分。根据标准，保留字决不能用做其他标识符。非保留字只是在特定的环境里有特殊的含义，而在其他环境里是可以用做标识符的。

标识符的命名需要遵守如下规范：

- 标识符需要为字母、下划线、数字（0-9）或美元符号（$）。
- 标识符必须以字母（a-z）或下划线（\_）开头。

>[!NOTE]说明
>
>- 此命名规范为建议项，非强制项。
>
>- 特殊情况下可以使用双引号规避特殊字符报错。
