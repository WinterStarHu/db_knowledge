These settings configure the ClickHouse server and are autogenerated from ClickHouse source.

## logger.async {#logger.async}

When `` (default) logging will happen asynchronously (one background thread per output channel). Otherwise it will log inside the thread calling LOG.

## logger.async_queye_max_size {#logger.async_queye_max_size}

When using async logging, the max amount of messages that will be kept in the the queue waiting for flushing. Extra messages will be dropped. Rounded up to the next power of two (e.g. `100000` becomes `131072`).
