These settings configure the ClickHouse server and are autogenerated from ClickHouse source.

## encryption_header_cache_policy {#encryption_header_cache_policy}

Encryption header cache policy name.

## encryption_header_cache_size {#encryption_header_cache_size}

Maximum size of the cache of encryption headers read from encrypted files. Used only by the experimental ReaderExecutor read path.

## encryption_header_cache_size_ratio {#encryption_header_cache_size_ratio}

The size of the protected queue (in case of SLRU policy) in the encryption header cache relative to the cache's total size.
