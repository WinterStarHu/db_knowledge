These settings configure the ClickHouse server and are autogenerated from ClickHouse source.

## shutdown_wait_backups_and_restores {#shutdown_wait_backups_and_restores}

If set to true ClickHouse will wait for running backups and restores to finish before shutdown.

## shutdown_wait_unfinished {#shutdown_wait_unfinished}

Delay in seconds to wait for unfinished queries on shutdown. Also bounds the wait for running backups and restores when `shutdown_wait_backups_and_restores` is disabled.

## shutdown_wait_unfinished_queries {#shutdown_wait_unfinished_queries}

If set true ClickHouse will wait for running queries finish before shutdown.
