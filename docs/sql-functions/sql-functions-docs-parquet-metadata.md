These settings configure the ClickHouse server and are autogenerated from ClickHouse source.

## parquet_metadata_cache_max_entries {#parquet_metadata_cache_max_entries}

Maximum size of parquet metadata files cache in entries. Zero means disabled.

## parquet_metadata_cache_policy {#parquet_metadata_cache_policy}

Parquet metadata cache policy name.

## parquet_metadata_cache_size {#parquet_metadata_cache_size}

Maximum size of parquet metadata cache in bytes. Zero means disabled.

## parquet_metadata_cache_size_ratio {#parquet_metadata_cache_size_ratio}

The size of the protected queue (in case of SLRU policy) in the parquet metadata cache relative to the cache's total size.
