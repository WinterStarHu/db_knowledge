These settings configure the ClickHouse server and are autogenerated from ClickHouse source.

## max_remote_read_connections {#max_remote_read_connections}

Maximum number of open remote read connections kept alive by `ReaderExecutor` for sequential read optimization. 0 disables connection reuse.

## max_remote_read_network_bandwidth_for_server {#max_remote_read_network_bandwidth_for_server}

The maximum speed of data exchange over the network in bytes per second for read.

## max_remote_write_network_bandwidth_for_server {#max_remote_write_network_bandwidth_for_server}

The maximum speed of data exchange over the network in bytes per second for write.
